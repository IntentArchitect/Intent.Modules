## Service Settings

The naming convention settings rename elements as they are created or renamed in the Services designer. Each can be set to `Manual` (names are left as typed), `Pascal Case` or `Camel Case`.

| Setting | Applies to |
|---|---|
| Entity Naming Convention | Services, DTOs, Commands and Queries |
| Operation Naming Convention | Operations |
| Parameter Naming Convention | Operation parameters (default `Camel Case`) |
| Property Naming Convention | DTO fields |
