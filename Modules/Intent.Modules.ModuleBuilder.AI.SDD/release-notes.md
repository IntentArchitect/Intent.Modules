### Version 1.0.0

- New Feature: Adds the `sdd-build-module` skill — the Intent Architect module-building SDD experience end to end. It routes on one question ("do you have a reference golden sample?"): an existing sample gets documented into a Golden Sample Reference; a missing one gets built in a planning session via a prepared prompt (`write_plan` for a developer co-owned scaffolding plan, `implement_plan` for the approval card, then dev-and-AI execution), with the plan document finishing in Reference form. Requirements start only once the Reference exists and record its path; the developer stipulates the module's actual surface, extrapolations beyond the sample are flagged in plain language, and variations are proven by test applications generated from the module rather than by growing the sample.
- New Feature: Adds the `sdd-wave-evidence` instruction file — the obligations that must survive into implementation sessions that never ran the planning phase: an evidence contract for SDD waves (file paths, model changes, the exact command and its output, and traceability confirmation per ticked task), a find-the-Golden-Sample-Reference-first step, and the `GOLDEN-SAMPLE:` marker sweep, where removing a marker's temporary code-management directive and confirming the template reproduces that exact line is the per-line parity proof.
