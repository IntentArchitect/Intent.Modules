# Intent.ModuleBuilder.AI.Skills

> [!WARNING]
>
> Obsolete. This module can safely be uninstalled.

This module used to drop AI agent skill files and instruction files for building Intent Architect modules into the repo it was installed in. From version 1.2.0 it generates nothing:

- `intent-module-orchestrator`, `module-building-strategies` and `module-svg-icon`, and the `exception-guidelines` and `known-build-gotchas` instructions, are generated by `Intent.ModuleBuilder.AI.Guidelines`, which this version installs as a dependency.
- `file-builder-expert`, `intent-metadata-consumer`, `add-designer-extension`, `add-module-migration`, `architecture-templates`, `module-docs` and `module-versioning` are built into Intent Architect from 5.4.0.

Version 1.2.0 requires Intent Architect 5.4.0 or later. On earlier versions Intent Architect installs version 1.1.0, which still generates the module's own skills.

## Related Modules

- `Intent.ModuleBuilder.AI.Guidelines` now carries this module's remaining skills and instructions.
